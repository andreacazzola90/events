# BMAD Documentation Workspace

Last update: 2026-05-27

This folder organizes BMAD-oriented project artifacts so planning and implementation documents stay in one predictable location.

## Structure

- planning artifacts: [planning-artifacts](./planning-artifacts)
- implementation artifacts: [implementation-artifacts](./implementation-artifacts)

## Suggested conventions

Planning files:
- PRD: prd-YYYY-MM-DD.md
- architecture: architecture-YYYY-MM-DD.md
- epics/stories map: epics-stories-YYYY-MM-DD.md
- sprint plan: sprint-plan-YYYY-MM-DD.md

Implementation files:
- story implementation notes: story-<id>-implementation.md
- rollout checklists: rollout-YYYY-MM-DD.md
- post-release review: post-release-YYYY-MM-DD.md

## BMAD runtime references

Installed runtime and skills are in:
- [_bmad](../../_bmad)
- [.claude/skills](../../.claude/skills)

This docs folder is for project-level curated outputs, while runtime BMAD folders remain tool-managed.
